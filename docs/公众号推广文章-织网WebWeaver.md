# 轻量级网络巡检神器「织网」：树状监控 + 历史图表 + 一键 Docker 部署

各位小型公司的网络管理者，是不是经常有这样的烦恼：

- 设备一多，网络拓扑混乱，谁在线谁离线全靠猜？
- 想监控核心设备状态，又不想搭一套重型的 Zabbix / Prometheus？
- 手里只有一台 512MB 内存的小主机 / 软路由，很多监控系统根本跑不动？
- 手动 Ping 几十台设备，点到手软？

今天给大家介绍一个开源、轻量、好上手的自动化网络状态检测平台——**织网（WebWeaver）**。

## 一、它是什么？

织网是一个**树状结构的自动化网络状态检测平台**，后端定时自动巡检，前端以树形结构展示设备层级和实时状态，还带巡检历史记录和延时图表。你只需要把设备挂到树上，剩下的交给它。

它自带漂亮的前端界面（Vue 3 + Element Plus），浏览器访问即可使用，无需安装任何客户端。

## 二、核心功能一览

**1. 树状设备管理**

按层级组织你的设备，父子结构一目了然。支持添加子节点、同级节点、编辑、删除，右键一键操作。手机端还支持横向滚动，深层级也不会挤成一团。

**2. 自动巡检，实时状态**

调度器默认每 5 分钟巡检一次（可自定义），用 ICMP Ping + 可选 TCP 端口探测来判定设备状态：

- Ping 成功 → **在线**
- Ping 成功但端口不通 → **告警**
- Ping 失败 → **离线**

树节点实时着色，一眼看清全网健康度。

**3. 巡检历史 + 延时图表**

每次巡检自动写入历史记录，右键节点「查看历史」即可弹出**平均延时柱状图**，支持按小时/按天切换、最近 1/7/30 天范围选择。历史默认保留 30 天，自动清理，不占空间。

**4. 外网目标监控**

内置外网目标列表，监控公网可达性，网络出问题第一时间发现。

**5. 设备图片**

给设备挂上照片或截图，一目了然知道这是哪台机器（自动压缩至最长边 1600px、不超过 300KB，上传超过 30MB 会被拒绝）。

**6. 多用户管理**

支持多用户登录、权限区分（admin 管理员），适合团队共用。

**7. 一键备份与恢复**

数据随时备份，出问题秒级还原，再也不怕配置丢失。

## 三、为什么值得一试

**极轻量**：Python + SQLite，单容器部署。实测 **512MB 内存**的小主机即可流畅运行，连 48MP 大图上传、处理也没问题（512MB 以下未测试上传，建议 ≥512MB）。

**部署超简单**：只有一个 Docker 镜像，多架构支持（amd64 / arm64），NAS、软路由、树莓派通吃。数据持久化到 Docker 卷，升级、重建容器都不丢数据。

**完全开源**：代码托管在 GitHub，可自行研究、二次开发。

## 四、安装教程（Docker 部署）

### 一键docker：docker run（最简单）

istoreos上已测试过的方法
打开终端,复制下面内容,执行
```bash
docker pull ghcr.io/langdalebecks204-bit/webweaver:0.3.2
docker run -d --name weaver \
  -p 8000:8000 \
  --cap-add=NET_RAW \
  -v webweaver-data:/data \
  -e WEAVER_JWT_SECRET="u9zaM2CB4qs9niYV1d4JzvLuBMw23UYXiGAHtwcUJWlOzX1l" \
  ghcr.io/langdalebecks204-bit/webweaver:0.3.2
```

> `--cap-add=NET_RAW` 是 ICMP Ping 必需（不加就只能 TCP 探测）。数据保存在 `webweaver-data:/data` 卷中。



### 使用

浏览器打开 `http://你的主机IP:8000`，用默认账号 **admin / admin123** 登录（生产环境务必通过环境变量改掉密码）。

登录后右键根节点，开始添加你的设备吧。

### 升级版本

固定 tag 部署时，拉取新镜像、重建容器即可，数据不会丢：

```bash
docker pull ghcr.io/langdalebecks204-bit/webweaver:最新tag
docker rm -f weaver
docker run -d ... ghcr.io/langdalebecks204-bit/webweaver:最新tag
```
